# 💰 Darija Expense Tracker

A simple, lightweight Command Line Interface (CLI) application built with Python to help you track your daily expenses. This tool is designed for simplicity and saves your data locally in a JSON format.

## 🚀 Features
- **Add Expenses:** Record amount (in Dh), category, description, and date.
- **View History:** Display all recorded expenses in a clean table format.
- **Total Calculation:** Instantly get the sum of all your spending.
- **Data Persistence:** Automatically saves and loads your data using a `expenses.json` file.

## 🛠️ Installation & Usage
1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate to the folder:**
   ```bash
   cd darija-expense-tracker
   ```
3. **Run the app:**
   ```bash
   python main.py
   ```

## 📁 File Structure
- `main.py`: The main Python script.
- `expenses.json`: (Auto-generated) Where your data is stored.
- `README.md`: Project documentation.
